# Олимпиадный календарь 4–5

Общий календарь олимпиад для родителей: дети, даты участия, итоги туров. Смотреть может любой, у кого есть ссылка, а менять — только тот, кто знает общий PIN-код.

Устроен так же, как склад: страница на GitHub Pages, данные в Google Таблице через Google Apps Script.

| Файл | Что делает |
|---|---|
| `index.html` | Страница календаря |
| `seed.json` | Начальные данные: 62 олимпиады и дети (Аня, Даня, Настя) |
| `apps-script/Code.gs` | Серверная часть для Google Apps Script |

## Подключение Google Таблицы (один раз, около 5 минут)

1. Откройте [script.google.com](https://script.google.com) → «Новый проект». Удалите пример и вставьте весь код из `apps-script/Code.gs`. Сохраните.
2. В функции `setPin` замените `1234` на свой PIN. Выберите `setPin` в списке функций и нажмите «Выполнить». Google попросит разрешения — подтвердите.
3. «Начать развёртывание» → «Новое развёртывание» → тип «Веб-приложение». «Запуск от имени»: **Я**, «У кого есть доступ»: **Все**. Нажмите «Начать развёртывание» и скопируйте адрес вида `https://script.google.com/macros/s/…/exec`.
4. Впишите этот адрес в `index.html` вместо `ВСТАВЬТЕ_АДРЕС_APPS_SCRIPT` (строка с `const API_URL`).

При первом открытии скрипт сам создаст Google Таблицу «Олимпиадный календарь — данные» у вас на Диске и загрузит в неё `seed.json`.

## Как это работает

- Страница обновляется каждые 20 секунд и при возвращении на вкладку.
- PIN запоминается на устройстве после первого ввода. Кнопка «PIN введён» в шапке позволяет его забыть.
- Сменить PIN: поменяйте значение в `setPin` и выполните её снова (или задайте свойство `EDIT_PIN` в настройках проекта Apps Script).
- После изменения `Code.gs` нужно «Управление развёртываниями» → карандаш → «Новая версия», чтобы адрес остался прежним.
